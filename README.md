# Unity 3D 플랫포머: '슈퍼마리오3D월드 1-1' 클론 코딩
## Unity 3Dプラットフォーマー：「スーパーマリオ3Dワールド１－１」再現開発)

Unity 엔진을 사용하여 '슈퍼 마리오 3D 월드'를 오마주한 3D 플랫포머 액션 게임입니다. 물리 기반의 플레이어 컨트롤러, 상태 머신 기반의 적 AI, 다양한 상호작용 오브젝트 구현에 중점을 두었습니다.

This project is a 3D platformer game developed with Unity, inspired by 'Super Mario 3D World'. The main focus was on implementing core gameplay mechanics such as a physics-based player controller, a state machine-based enemy AI, and various interactive objects.
